# The Sunday Edit – Multi-Page Blog Website

## Project Description
The Sunday Edit is a multi-page blog website created using HTML, CSS and JavaScript. It provides a simple and user-friendly layout with a home page, blog page and contact page.

## Pages
- Home – Introduction and hero section.
- Blog – Displays four blog post cards.
- Contact – Contact information and contact form.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Google Fonts
- Font Awesome
